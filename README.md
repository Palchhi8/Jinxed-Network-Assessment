# AI Generative Media Studio

A modern AI-powered media generation platform built with Next.js, TypeScript, Prisma, Supabase, Hugging Face Inference API, and Fabric.js.

## Features

- AI image generation from prompts
- Advanced generation settings
- Dynamic generation gallery
- Tweak & regenerate workflow
- Async image processing
- Responsive modern UI
- Fabric.js creative editor
- Text overlay editing
- Export edited images

## Tech Stack

### Frontend
- Next.js 15
- TypeScript
- Tailwind CSS

### Backend
- Next.js API Routes
- Prisma ORM

### Database
- Supabase PostgreSQL

### AI Integration
- Hugging Face Inference API

### Creative Editing
- Fabric.js

## Architecture Highlights

- Async AI generation workflow
- Provider abstraction for scalable AI integrations
- Prisma parent-child relationship for tweak history
- Modular component-based frontend architecture
- Persistent generation history with Supabase
